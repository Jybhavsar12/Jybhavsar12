## About

Software engineer based in the Greater Toronto Area, with a Computer Programming diploma from Humber Polytechnic. I build full-stack web applications and backend systems, with a particular interest in distributed systems and application security.

- Currently focused on distributed storage and cloud infrastructure (Python, AWS)
- Full-stack experience with React, Node.js, TypeScript, Python, and Java
- Security background: container hardening, vulnerability assessment, and network security labs
